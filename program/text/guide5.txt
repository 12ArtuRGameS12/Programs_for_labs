Косвенные измерения - дельта значение от формулы.

Формула - использует библиотеку sympy, поэтому пишите формулу по стандарту python и этой библиотеки.
Например: 'log(piu, g*5) + FG**2'.

Значения - список переменных через пробел которые имеют погрешность.
Например: 'piu g FG'.

Результат - погрешность формулы.
